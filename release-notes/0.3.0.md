## Novità: vulnerabilità note (CVE)

- **Ricerca CVE dalle versioni dei servizi.** nmap riconosce prodotto e versione dei servizi (es. `openssh 9.6p1`) e SubnetScout cerca le CVE corrispondenti nel database **NVD del NIST**.
- **Privacy.** È **disattivata di default**: si attiva con «Cerca vulnerabilità note (CVE)» nella sidebar oppure in Impostazioni (⌘,). A NVD viene inviato **solo nome e versione del software**, mai indirizzi, nomi o altri dati dei dispositivi.
- **Un problema per ogni servizio vulnerabile.** Ha la gravità della CVE peggiore e indica il numero di CVE, il CVSS massimo e quante sono **sfruttate attivamente** secondo il catalogo CISA KEV. Le CVE nel KEV contano almeno come «Alta».
- **Dettaglio del dispositivo.** C'è l'elenco delle CVE per porta, con punteggio, descrizione, data e link alla scheda NVD. Anche il report HTML ha una nuova sezione «Vulnerabilità note».
- **Cache e velocità.** Le risposte restano in cache sul Mac per 7 giorni. Una **chiave API NVD** gratuita, salvata nel Portachiavi, rende la prima ricerca circa 10 volte più veloce.

La corrispondenza è basata sulla versione dichiarata dai servizi. Router, NAS e telecamere spesso correggono le falle senza cambiare versione: i risultati vanno verificati sul dispositivo.

## Dopo l'aggiornamento

L'helper è cambiato: premi **Reinstalla** nella sidebar e riapprovalo in Impostazioni di Sistema › Generali › Elementi login ed estensioni.
