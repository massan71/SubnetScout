## What's new: network map

- **Map tab.** A new view next to Devices, Issues and Network shows the network as a star around the gateway, with devices grouped by type in sectors (servers, computers, printers, TVs, IoT, phones…).
  - Each node's ring shows the severity of its worst issue (green when audited and clean), a dashed orange ring marks NEW devices and a badge marks UPnP routers.
  - Click a node to open its details; drag to pan, pinch or use the buttons to zoom.
  - "All names" shows every label, "Only with issues" dims the clean devices. Labels never overlap: the less important ones are hidden when there is no room.
  - Links are logical (through the gateway): nmap cannot see the physical cabling.
- **Map in the HTML report.** The report has a new "Network map" section with the same layout, as inline SVG (no scripts, strict CSP kept).
