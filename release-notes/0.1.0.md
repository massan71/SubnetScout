First release of **SubnetScout**, a native macOS network scanner built on nmap.

## Features

- **Subnet discovery**:
  - detects the interface and network by itself;
  - reads MAC addresses even without privileges (from the ARP table);
  - derives the vendor from nmap's OUI database and recognizes randomized MACs;
  - classifies devices (routers, NAS, printers, cameras, IoT…).
- **Scan profiles**: Discovery, Quick (top 100 ports), Standard + audit (top 1000 ports with safe NSE scripts), Full (65535 TCP ports, plus the main UDP ports as administrator).
- **Security audit** with about 30 rules: cleartext Telnet and FTP, anonymous FTP, SMBv1 and SMB signing not required, obsolete or weak TLS, expired certificates, RDP without NLA, VNC without a password, exposed databases, Docker API, SNMP `public`, UPnP and more. Every issue comes with a recommended fix.
- **Risk**: score from 0 to 100 per device and per network, with a grade from A to F.
- **History and comparison**: shows new devices, opened or closed ports and new issues compared with the previous scan. Devices you mark as known lose the "NEW" badge.
- **Report**: HTML (light and dark, printable to PDF), CSV and JSON.
- **Privileged helper** (SMAppService + XPC) for administrator scans without a password, with progress and cancellation:
  - it only runs an nmap entirely owned by root;
  - with Homebrew's nmap it falls back to asking for the password;
  - with the nmap.org package it can create a protected copy of nmap.

## Known limitations

- Ad-hoc signed and not notarized build.
- With ad-hoc signing, after an update the helper must be reinstalled and approved again ("Reinstall" button).
