## What's new: device names from Bonjour

- **Readable names.** SubnetScout asks Bonjour/mDNS what devices are called: "HP LaserJet MFP M140w", "Sonos Roam", "Office", the name of a Home Assistant bridge and so on, instead of IPs, private MACs or generic `.lan` names.
- **Model and services.** The device details show the **model** (from the TXT records: printers, Macs, TVs, speakers…) and the announced **Bonjour services**.
- **More accurate classification.** Printers, TVs with Chromecast, Sonos and AirPlay speakers, Matter, HomeKit and Shelly devices, NAS and Macs are recognized from the services they announce themselves. For example, a TV named "camera.da.letto" (Italian for bedroom) is no longer mistaken for a camera.
- **Search, report and diagnostics.** Search also finds Bonjour names and models, the HTML report shows the model in the inventory, and `--diagnose-network` lists the Bonjour devices found by the helper.

Discovery uses the macOS Bonjour service (mDNSResponder): it opens no connections to the devices. With the helper active it always works. Without the helper it depends on the Local Network permission, which macOS can deny the app.
