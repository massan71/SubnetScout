## Stability and interface polish

- **Setup assistant on first launch**: responsible use, nmap check (with instructions to install it), helper installation and options (CVE, daily scan, notifications, menu bar). Reopen it from Help › Setup Assistant…
- **The app no longer freezes at launch.** The encrypted history is loaded in the background. If macOS asks for Keychain access, the interface stays usable and the history appears as soon as you allow it.
- **More readable results.**
  - The "Risk" column is always visible, without horizontal scrolling.
  - The header with the tabs can no longer end up under the title bar.
- **Correct grade for Discovery.** A Discovery shows "Audit not run" instead of a misleading "A" grade, in the history too.
- **"Mark All as Known" suggestion** when almost every device shows as NEW, so notifications and badges only concern devices that are really new.
- **Edge cases handled better.**
  - Clear message if the Mac is not connected to any network.
  - If the target is no longer the current network (for example after switching Wi-Fi), the app offers "Use Current Network".
  - If a scan cannot be saved to the history, a warning appears instead of a silent error.
  - During the first check the helper shows "Checking…" instead of a misleading message.
- More precise wording ("1 gone", "As administrator: OS, UDP and DHCP probe").

## After updating

- **Keychain**: macOS asks again for access to the history. Choose "Always Allow".
- **Helper**: click **Reinstall** and approve it again.

Both prompts come back after every update until the app is signed with an Apple Developer ID.
