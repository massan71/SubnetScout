## Data security

- **Encrypted history.** Saved scans contain the network inventory with vulnerabilities and CVEs: they are now encrypted with AES-256-GCM, with a random key stored in the Keychain and valid only on this Mac. The history folder is accessible only to your user. Scans from earlier versions are encrypted automatically on first launch and the plaintext originals deleted. The JSON export stays in plaintext, because it is an export you make yourself.
- **Better protected HTML report.** The report has a Content-Security-Policy that blocks scripts and external resources, and it sends no referrer when you follow a link (for example to the NVD pages).
- **Check of the protected nmap copy.** Before activating it, the helper compares the size and checksum of every file with the receipt of the official nmap.org installer. If `nmap.app` was modified after installation, the copy is not created. The receipt checksum is a CRC: it guards against accidental or trivial changes, it is not a cryptographic signature.
- **NVD cache** accessible only to your user.
